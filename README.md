# context-meter

Панель «Контекст»: заполненность контекстного окна Claude, цветом (до 40% зелёный, 40–60% жёлтый, от 60% красный). Обновляется после каждого ответа. Команда `/context-meter` снова открывает панель.

## Установка (терминал Claude Code)

```
/plugin install context-meter --marketplace O2KO/context-meter
```

Затем `y` (добавить маркетплейс) и область user.
